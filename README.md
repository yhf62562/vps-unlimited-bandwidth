## 叫“不限流量”的有三种，JustHost 是哪种

达量降速是最常见的一种。DMIT 的洛杉矶 LAX.Pro 系列标着 1000GB 月流量，超额后不限流量但把速度压到 4Mbps，MINI 及以上压到 8Mbps，MEDIUM 以上压到 10Mbps。流量确实不封顶，跑完额度后体验会掉一个量级。

窄带宽真不限是第二种。LisaHost 的 CN2 GIA 不限流量系列从 1Mbps ¥30/月一直排到 20Mbps ¥1999/月，没有月度流量额度，因为带宽本身就是天花板。1Mbps 换算下来一个月也就 300GB 出头，适合轻量建站和挂机，拿来跑大流量业务等于没有。

宽端口加公平共享是第三种，JustHost 属于这一类。端口给到 300 至 750Mbps，官方在带宽后面注明“公平共享（fair-share）”，并给出换算值“相当于每月 93+ TB”。这句话的含义是：端口速率是上限，实际能跑多少取决于同宿主机上其他用户当时的负载。想摆脱共享，附加服务里有两条路，+10 Mbps 收 ¥16.80/月，独享 1 Gbps 收 ¥2240.85/月。后一个数字也反过来说明，默认那 300Mbps 是共享资源。

KernelHost 的首尔机房是另一种表述方式。它同样标无限流量，但明确写着“没有月度流量额度，达到一定数据量后不会降速，也不按 TB 计费”，最高 1 Gbps，起步价 €40.99/月。这句话把“不降速”写进了产品页，是三种形态里承诺最直白的一种。

看一个“不限流量”套餐，先找三样东西：有没有月度额度、超额后限速到多少、端口是独享还是共享。JustHost 的答案分别是无额度、未设降速条款、公平共享。

## 300Mbps 一个月能跑多少 GB

这条换算法则比任何套餐名都有用：1Mbps 的理论下载峰值是 125KB/s，持续满载一天约 10GB，一个月约 300GB。

按这个基数往上乘：2Mbps 约 600GB/月，20Mbps 约 6TB/月，300Mbps 约 93TB/月，500Mbps 约 155TB/月，750Mbps 约 232TB/月。JustHost 在页面上标注的“300 Mbps 相当于每月 93+ TB”“500 Mbps 相当于每月 124+ TB”，用的就是这套算法。

反过来用更实用。先估自己一个月的实际出站流量，再除以 300GB，就是你需要的最低 Mbps 数。跑爬虫每天抓几十 GB，一个月 1TB 出头，4Mbps 就够；做流媒体中转给十几个人共享，一个月 3 至 5TB，20Mbps 有余；只有做视频分发或大规模数据同步，才会真的碰到 300Mbps 这个量级。

结论很直接：JustHost 最便宜的 Sirius 那 300Mbps，对个人和中小项目都是过剩的。你升级套餐的理由通常是要更大内存或更大硬盘，而不是嫌带宽不够。真嫌不够，+10 Mbps 的价格是 ¥16.80/月，也没必要为此跳档。

## 常见问题

**JustHost 的不限流量会达量降速吗？**
官网写的是“不限流量端口 300 Mbps（公平共享）”，没有设置月度流量额度，也没有列出达量降速的档位表。需要理解的是“公平共享”本身：端口带宽由同宿主机用户分时使用，长时间满载会影响邻居，也可能触发资源管理。它和 KernelHost 那种把“达到一定数据量后不会降速”写进页面的承诺，不是一个措辞强度。

**能换机房和 IP 吗？**
可以。官方写明随时在用户中心更换 VPS 机房、更换 IP 地址，这是它 80 个机房这个卖点的实际用法。换机房不需要重新购买。

**多久能开通？支持什么系统？**
官方流程是选套餐、下单、付款，付款完成后即可访问控制面板和设置。系统方面官网只写了通过 SSH 访问、可复制编辑文件、运行 bash 脚本、支持 IPv6，没有逐条列出可用发行版，具体镜像在开通后的面板里看。

**能退款吗？**
官网当前页面的套餐与 FAQ 部分没有写明退款期限。这一条必须在下单前的结算页和条款里确认，别按别家的惯例套。

**一个人用 300Mbps 是不是浪费？**
大概率是。按 300GB/月/Mbps 的换算法，300Mbps 对应 93TB，个人用户一个月跑 1TB 都算重的。真正限制你的是 CPU、内存和磁盘 IO，不是端口。
